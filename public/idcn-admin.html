Add a student 添加学员

New students sign terms idcn3-v4: ฿192,600 (฿180,000 + 7% VAT), the same for every new student. Students who signed earlier keep their own terms.

Add several students 批量添加

One line per student: Name EN | 中文名 | member code or email | start date | note | arranged (yes/no). Only the name is needed. A member code links the AYBKK account they already have (alumni); an email links the account with that email, or makes one (new students). Start date is YYYY-MM-DD; empty means from day 1 (alumni joining later: 2027-01-24, day 14, from session #13). arranged yes = terms agreed directly with AYBKK, so the course opens without the online signature. Up to 30 lines. Rows copied from a spreadsheet (tabs) work too. Someone already on the course is never added twice: only their empty fields are filled.

Calendar 课程日历

Paste the CN #3 table as it was sent (markdown with | pipes, or rows copied from a spreadsheet). The header row names the columns: Day no. | Date | Day | Morning class | Slot A 10:30-12:30 | Slot B 13:00-16:00. A slot cell that starts with #N (or SN, as S31) is session N; the morning column is never a session. Lines around the table are fine, and a line such as "Slot A is 10:30-12:30." sets that slot's time. Save replaces the whole calendar.
