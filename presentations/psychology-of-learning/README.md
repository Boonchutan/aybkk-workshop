# The Psychology of Learning — teacher-training deck

A 13-slide, bilingual (EN + 中文) distillation of the AYBKK teacher-training evidence map:
the 3-part core frame → strongest tools (external focus, feedback-fading, mastery, autonomy)
→ dropout & habit → teacher blind spots → talking to prospects (MI) → Chinese learners →
the myths to drop → the staged playbook (prospects / new / experienced / teacher) → close.

## Files
- **`index.html`** — the deck. Open in a browser, `F` for full-screen, `→`/space to advance, `N` for the speaker note.

Warm-graphite editorial look; teal = evidence-backed, terracotta = warnings/myths, sage/gold as section accents. Offline, macOS-native fonts, no network. Full citations live in the Obsidian teaching note (`teaching/psychology-of-learning-for-ashtanga-teachers.md`).
