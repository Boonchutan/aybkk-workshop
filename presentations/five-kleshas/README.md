# The Five Kleshas — high-contrast bilingual deck

A 9-slide talk on the Five Kleshas (Yoga Sutras 2.3–2.9) — the roots of suffering —
deepened with the historical/mythological stories of how each affliction "turns things sideways."
For the Indepth China cohort. Bilingual EN + 中文 (+ Sanskrit in Devanagari).

## Files
- **`index.html`** — the presentation. Open in a browser, `F` for full-screen.
- **`talk-script.html`** — the speaker script (~18–20 min): SAY + full story + how-it-turns-sideways + antidote per slide, plus an "if a student pushes back" cheat-sheet.

## Presenting (fully offline — safe in China)
Double-click `index.html` → `F` full-screen → `→`/space next · `←` back · `N` speaker note · `Home`/`End`.
All fonts (Iowan Old Style · Avenir Next · PingFang SC · Devanagari Sangam MN) are macOS-native; every symbol/animation is embedded — no network.

## Design
High-contrast: warm near-black base, bone-white text, **ember `#B8442A`** for the afflictions that burn, **gold `#E4B45E`** reserved for the antidote / the light. One custom animated SVG symbol per klesha (rope→snake, crown+melting wings, ghee-fed flame, hand+coal, hand dropping a bone into water), plus root-field, four-states and doorway symbols. The deck moves from ember gravity (slides 3–7) into gold light (8–9).

## Stories & sourcing
Canonical (name the source): Yayāti (Mahābhārata Ādi Parva), Śiśupāla (Sabhā Parva), Nachiketā (Kaṭha Upaniṣad), Rāvaṇa (Vālmīki Rāmāyaṇa). Teaching parables (say "a story teachers tell"): the tiger-among-goats and rope-snake for avidyā. Structure per YS 2.4 (avidyā is the root field; the four states). Antidotes: kriyā yoga (2.1), pratipakṣa bhāvana (2.33), viveka.
