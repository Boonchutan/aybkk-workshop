# Hormones, Habit & the Nervous System — Indepth China #2

Redesigned, bilingual (EN + 中文) keynote + presenter script for the talk
*"Ashtanga Intensity & the Chemistry of Transformation."*

## Files
- **`index.html`** — the presentation. Open it in a browser and present full-screen.
- **`talk-script.html`** — your separate spoken script (SAY / ASK / DEPTH-DROP per slide,
  ~20 min). Read it on your phone or print it to PDF.

## Presenting (works fully offline — safe in China, no internet needed)
1. Double-click **`index.html`** (Safari or Chrome).
2. Press **`F`** for full-screen.
3. **`→`** or **space** = next slide · **`←`** = back · **`N`** = quick speaker note ·
   **`Home`/`End`** = first/last.
4. Fonts are all macOS-native (Iowan Old Style + Avenir Next + PingFang SC for Chinese) and
   every icon/animation is embedded — nothing loads from the network.

## Design
- **Warm-graphite** base with **per-hormone theming**: Testosterone = ember bronze,
  Cortisol = amber, Dopamine = coral, Serotonin = sage, brain/nervous-system slides = violet-slate.
- 18 slides, 16:9, custom animations, hand-drawn SVG symbols (insula, cortical map, dopamine
  loop, hormesis curve, etc.).

## Notes
- The old deck's "Protein → Recovery" line was corrected — cortisol is *catabolic* to protein;
  recovery happens when cortisol *falls*. A few science nuances (acute vs. chronic cortisol,
  gut vs. brain serotonin, small/short testosterone rise) are built into the script as
  authority "depth-drops," with an **"if a student pushes back"** cheat-sheet at the end.
- To edit copy or colors, everything is inline in the two HTML files. Byline reads
  *"Boonchu Tanti · Indepth China #2 · 2026"* — change on slide 1 if needed.
